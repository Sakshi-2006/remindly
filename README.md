# Remindly

Remindly is a responsive email automation and reminder dashboard built with Next.js. The interface, generated by the project as “Nudge,” helps users manage reminders, campaigns, contacts, email activity, and delivery performance from one workspace.

## Live App

[Open Remindly](https://remindly-olive.vercel.app)

## Features

- Dashboard overview with email, delivery, reminder, and contact metrics
- Campaign and reminder creation workflows
- Contact management
- Searchable and filterable recent activity
- CSV report export
- Responsive sidebar and mobile navigation
- Toast notifications for completed actions
- Vercel Analytics in production

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- PostCSS
- Lucide React
- shadcn-style UI utilities
- Vercel Analytics
- pnpm

## Getting Started

### Prerequisites

- Node.js 20 or later
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open `http://localhost:3000` in a browser.

### Production Build

```bash
pnpm build
pnpm start
```

## Project Structure

```text
app/             Next.js routes, layout, and global styles
components/ui/   Reusable interface components
lib/             Shared utility functions
public/          Static icons and image assets
```
